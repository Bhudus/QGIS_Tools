name=Layout from Template

description=Creates a print layout of the current map from a .qpt template, or a ready-made layout with title, legend, scale bar and north arrow.
version=1.4.0
changelog=1.4.0 - Scale bar uses two round-valued segments and a smaller font so its numbers no longer overlap.
    1.3.0 - Fit map to selected layer: zooms to the layer and resizes the map frame to its shape.
    1.2.0 - Legend has a visible frame; scale bar text stays inside the outer frame.
    1.1.0 - Template is optional: builds a default layout (title, map, legend, north arrow, scale bar, outer frame), landscape or portrait from the selected layer's shape.
    1.0.0 - First release: print layout from a .qpt template set to the current map canvas, as a Processing tool with optional PDF/image export.
author=Richard Cooke
email=raccooke@gmail.com
about=Pick a print layout template (.qpt), or leave it blank for a default layout with a title, legend, scale bar, north arrow and a frame around everything. The main map is set to the current map canvas, or zoomed to the selected layer with the map frame resized to the layer's shape so it just fits. The page is landscape or portrait to match the selected layer. Optionally exports the layout to PDF or an image. Runs from a toolbar button, the Plugins menu, or the Processing Toolbox, so it also works in models and batch mode.
