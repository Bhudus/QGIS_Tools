description=Bill of materials, cost estimate and printable quote, and set drainage coefficients (one value, by Strahler order or pipe by pipe) and pipe types (for the network or section by section) and resize the pipes of an Illini Subsurface Drain Layout network with Routine K.
about=Works on the Drainage network layer of Illini Subsurface Drain Layout. Choose one drainage coefficient for every line, one per Strahler order (TILE_ORDER), or click pipes on the map and give each its own; set the pipe type for the whole network or for single sections of a pipe, such as part of the main; the panel shows at once how the pipe sizes change (length by nominal size, now and after), and Apply to layer writes D_COEFF, PIPE_TYPE, CUM_SEG_FLOW, ACTUAL_SIZE, NOMINAL and D_AREA as one undoable edit. Sizing follows Routine K of the Illini Drainage Tools (Manning's equation for a full pipe, flow = FLOW_LENGTH x drain spacing x coefficient), as in Illini Subsurface Drain Layout. Uses only QGIS.
