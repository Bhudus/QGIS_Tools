name=Illini Subsurface Drain Layout
qgisMinimumVersion=3.34
description=Automated subsurface (tile) drainage layout, tile burying and pipe sizing from a DEM, field boundary, outlet and lateral spacing.
about=Lays out mains, submains and evenly spaced laterals running near parallel or near perpendicular to the field contours, in parallel/gridiron or herringbone patterns, around an automatically routed main or one you supply, with straight or contour-following laterals, as one connected network. Buries the tile with the scheme of Routine J (Tile Burying System) of the Illini Drainage Tools: from the outlet upstream, toward a target depth band, within minimum and maximum slopes and absolute depth limits, with optional constant slope, outlet offset and outlet lowering for low ground. Sizes the pipes with Routine K (Network Pipe Sizing), using the Strahler tile order of Routine G. Writes the Routine J fields (ElevDepth1/2, BuryDepth1/2, InSlope, OutSlope, BURY_CHECK), the Routine K fields (TILE_ORDER, D_COEFF, D_AREA, CUM_SEG_FLOW, ACTUAL_SIZE, NOMINAL) and a line-ID layer (Surface Layout) for the Illini Drainage Tools, and optionally a raster of tile elevation and depth that highlights where the tile is outside the depth limits. Uses only QGIS, GDAL and numpy. The burying and sizing schemes are ported from the Illini Drainage Tools by Anamelechi Falasy and Richard Cooke, University of Illinois Urbana-Champaign (GPL v3).

changelog=0.15.1 - Settings are saved each time the tool runs and reopen with it; Plugins → Illini Subsurface Drain Layout → Reset saved settings to defaults goes back to the plugin defaults.
    0.15.0 - New Sharpest bend setting (default 120 degrees between tile legs): sharper corners in laterals, connectors and generated mains are rounded, with junctions kept joined.
    0.14.1 - Fix: the Tile elevation raster now loads when written as a temporary output (QGIS was given a different temporary file name from the one written).
    0.14.0 - Default target grade for contour-following laterals 0.1%. Optional Tile elevation raster (made by default; skip it in the outputs): tile elevation, tile depth and a depth check on the analysis grid, loaded with a Tile depth check layer that highlights where the tile is shallower than the minimum cover or deeper than the maximum depth.
    0.13.0 - The Drainage network layer now stores the tile elevation (Z) and ground elevation (M) at every vertex, with every Routine J grade break kept as a vertex, for the Tile Profile plugin.
    0.12.0 - Also listed under Raster → Tile Drainage with the other drainage tools (existing menu entry kept).
    0.11.1 - New icon: a field with its parallel laterals and main.
    0.11.0 - Straight laterals can also run northwest-southeast or northeast-southwest. A fixed-bearing header now gets out of a narrow corner at the outlet.
    0.10.0 - New "Straight laterals: bearing" setting: keep straight laterals running north-south or east-west (map grid); with the parallel pattern the main runs at right angles to them, following the field edge.
    0.9.0 - Pipe sizing corrections to Routines G and K: single-wall pipe now uses Manning's n by size (0.015 up to 8 in, 0.017 to 12 in, 0.020 above; it was always 0.015); drain spacing is rounded to the nearest foot instead of truncated; tile order is the standard Strahler order at every junction. New TileLength field: length rounded to the nearest 5 ft, or the nearest metre.
    0.8.0 - Pipe sizing with Routine K (Network Pipe Sizing) of the Illini Drainage Tools, using the Strahler tile order of Routine G: pipe material, drainage intensity or per-order drainage coefficients, InSlope or OutSlope; Routine K fields (TILE_ORDER, FLOW_LENGTH, D_COEFF, D_AREA, CUM_SEG_FLOW, ACTUAL_SIZE, NOMINAL) and pipe length by nominal size.
    0.7.1 - Lengths in flags, warnings and log messages are now given in the design units (feet or metres).
    0.7.0 - Optional user-supplied main line(s): the line ending nearest the outlet is the main, other lines become submains; lines may run outside the field; the outlet is optional when a main is given. The line-ID output layer is renamed Surface Layout (parameter SURFACE_LAYOUT). Laterals now run down the slope by default.
    0.6.0 - First public release. Automated layout (parallel/gridiron or herringbone; straight or contour-following laterals, near parallel) as one connected network, tile burying with the Routine J scheme of the Illini Drainage Tools, Routine J output fields and a line-ID layer.
