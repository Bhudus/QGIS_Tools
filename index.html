Tools

QGIS plugins for drainage and terrain work. Each card links to the plugin's folder on GitHub, with its README, install steps and source code, and to its zip file for installing in QGIS. Once installed, the drainage tools are grouped under Vector → Tile Drainage and Raster → Tile Drainage in QGIS.

Grids scattered point data into a raster using minimum curvature (with optional tension) or natural neighbor interpolation.

Plugin · v0.13.0

Illini Subsurface Drain Layout

Lays out, buries and sizes a tile drainage network in one run, from a DEM, field boundary, outlet and spacing, using the burying and pipe-sizing schemes of Illini Drainage Tools routines J and K. Straight laterals can follow the terrain or run north-south, east-west or diagonally. The network stores tile and ground elevations at every vertex for the Tile Profile plugin.

View on GitHubDownload zip file
Plugin · v0.2.0

Tile Profile

Select a lateral or main and a docked panel draws its profile: the ground, the target and absolute tile-depth lines, and the tile with its grade breaks, junctions and section slopes.

View on GitHubDownload zip file
Plugin · v0.5.0

Illini Main Tile Locator

Finds the best tile main from an outlet you click, a DEM and a field boundary, for laterals parallel or perpendicular to the contours. Scores dozens of candidate mains by how much of the field their laterals can drain to, buries them with Illini Drainage Tools routine J, and returns the chosen main and four runners-up, labelled by rank. Can also add submains until the field is covered. Maximum lateral length defaults to the capacity of a 4-inch tile on a 0.1% slope. A curved main can be smoothed or turned into straight sections of a minimum length.

View on GitHubDownload zip file
Plugin · v2.0.2

Tile Drainage Layout

Guides hand-digitizing a tile layout: draws a setback line half the tile spacing inside each field boundary, optionally fills it with parallel laterals at the angle you set (or parallel to the longest edge), and connects them to a main you supply, with a junctions layer of tees and crosses.

Plugin · v0.3.0

DRAINMOD Climate-Scenario Weather Files

Writes ready-to-use DRAINMOD .RAI, .TEM and .PET weather files for future climate scenarios, from downscaled CMIP6 projections (NASA NEX-GDDP-CMIP6 or LOCA2) for a point or a layer of points, across several models and SSP scenarios at once.

Plugin · v0.1.0

DRAINMOD Soil File Builder

Click a point to build a DRAINMOD soil input (.soi) file from SSURGO. Combines horizons into at most five layers and computes the soil water characteristic with the van Genuchten equation, using Rosetta or Carsel & Parrish texture-class parameters or the Rosetta 3 web service.

View on GitHubDownload zip file
Plugin · v0.4.0

LiDAR Field DEM

Builds a bare-earth DEM for a field from Illinois Height Modernization (ISGS) or USGS 3DEP LiDAR, downloading only the tiles it needs. Lists the collection years available, lets you trace the field on the map, extends the DEM beyond the field for outlets, optionally fills sinks (Wang & Liu), and runs in the background.

Plugin · v0.4.0

Depressions and Laylines

For subsurface drainage design: maps the depressions in a field deeper than a set depth (filled minus unfilled DEM, default 0.75 ft) with their area, depth and storage, and the laylines (flow channels) with stream order and contributing area. Adds contours from the filled DEM and colors the DEM green to brown over a hillshade.

View on GitHubDownload zip file
Plugin · v1.7.0

SSURGO Soil Map

Gets the Web Soil Survey soil map for a field boundary shapefile, or a field you trace on the map, and saves it as a shapefile labeled with the soil names, with acres, drainage class and hydrologic group for each soil, Hooghoudt drain spacing for a drain depth and drainage coefficient you enter, and an optional field outline.

View on GitHubDownload zip file
Plugin · v0.3.0

StreamStats Delineator

Click near a stream to delineate the watershed upstream of it with USGS StreamStats. Snaps to the nearest stream, adds the basin with its drainage area, the NHDPlus streams inside it, and sub-basins split at stream confluences with downstream routing links for hydrologic models.

Plugin · v1.4.0

Layout from Template

Creates a print layout of the current map from a .qpt template, or a ready-made layout with title, legend, scale bar, north arrow and frame. Fits the map to the selected layer and picks landscape or portrait to match it, with optional PDF or image export.

About

This site provides a set of free, open‑source QGIS tools for agricultural drainage analysis and design.

All tools are maintained in the QGIS_Tools GitHub repository, where users can access the source code, contribute, and follow updates.
