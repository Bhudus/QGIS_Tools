Tools

QGIS plugins for drainage and terrain work. Each link opens the plugin's folder on GitHub, with its README, install steps and source code.

Plugin · v1.1.1

Surface Interpolation

Grids scattered point data into a raster using minimum curvature (with optional tension) or natural neighbor interpolation.

View on GitHub
Plugin · v1.2.0

Line Angle

Click a line segment, or two points, to get its angle in degrees. Includes a Processing tool that writes every segment's angle to a field.

View on GitHub
Plugin · v1.0.0

Random Point Selection

Randomly selects a set number or percentage of points from a layer, with an optional seed for repeatable results.

View on GitHub
Plugin · v2.0.2

Illini Drainage System Design

Designs a complete tile drainage system in one run, from proposed tile lines to buried depths and pipe sizes, combining Illini Drainage Tools routines E to K.

View on GitHub
Plugin · v0.6.2

Subsurface Drainage Layout

Lays out a tile drainage network from a DEM, field boundary, outlet and spacing, around an automatically routed main or one you draw, with laterals near perpendicular or parallel to the contours, as one connected network ready for pipe sizing.

View on GitHub
Plugin · v0.9.0

Illini Subsurface Drain Layout

Lays out, buries and sizes a tile drainage network in one run, from a DEM, field boundary, outlet and spacing, using the burying and pipe-sizing schemes of Illini Drainage Tools routines J and K.

View on GitHub
Plugin · v1.0.0

Raster Extremes

Finds the cells with the maximum and minimum values of a raster band and gives their X and Y coordinates, with an optional point layer of the results.

View on GitHub
Plugin · v2.0

DRAINMOD Weather Files

Click a point to download daily rainfall and max/min temperature from Daymet and write ready-to-use DRAINMOD .RAI and .TEM weather files in one step.

View on GitHub
Plugin · v0.3.0

DRAINMOD Climate-Scenario Weather Files

Writes ready-to-use DRAINMOD .RAI, .TEM and .PET weather files for future climate scenarios, from downscaled CMIP6 projections (NASA NEX-GDDP-CMIP6 or LOCA2) for a point or a layer of points, across several models and SSP scenarios at once.

View on GitHub
Plugin · v0.1.0

DRAINMOD Soil File Builder

Click a point to build a DRAINMOD soil input (.soi) file from SSURGO. Combines horizons into at most five layers and computes the soil water characteristic with the van Genuchten equation, using Rosetta or Carsel & Parrish texture-class parameters or the Rosetta 3 web service.

View on GitHub
Plugin · v0.2.2

LiDAR Field DEM

Builds a bare-earth DEM for a field from Illinois Height Modernization (ISGS) or USGS 3DEP LiDAR, downloading only the tiles it needs. Lists the collection years available, lets you trace the field on the map, and extends the DEM beyond the field for outlets.

View on GitHub
Plugin · v1.5.0

SSURGO Soil Map

Gets the Web Soil Survey soil map for a field boundary shapefile, or a field you trace on the map, and saves it as a shapefile labeled with the soil names, with acres, drainage class and hydrologic group for each soil and an optional field outline.

View on GitHub

About

This site provides a set of free, open‑source QGIS tools for agricultural drainage analysis and design.

All tools are maintained in the QGIS_Tools GitHub repository, where users can access the source code, contribute, and follow updates.
