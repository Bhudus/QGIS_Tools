changelog=1.5.0 - New series field and label option: first word of the soil name (e.g. Drummer).

    1.3.0 - Removed the Illinois productivity index fields.
    1.2.0 - Fewer output fields; added Illinois productivity indexes.
    1.1.0 - Soil names stop at the first comma (no slope or flooding phase).
    1.0.0 - First release: SSURGO map units clipped to field polygons, labeled by soil name.
author=Richard Cooke
email=raccooke@gmail.com
about=Give it a field boundary (shapefile or any polygon layer), or trace one by clicking on the map. It sends each polygon to USDA-NRCS Soil Data Access, the database behind Web Soil Survey, and returns the soil map units clipped to the boundary with map unit symbol, soil name, dominant component, drainage class, hydrologic group and acres. The output is labeled with the soil name, can be saved as a shapefile, and can include the field boundary as a bold outline. Requires an internet connection.
