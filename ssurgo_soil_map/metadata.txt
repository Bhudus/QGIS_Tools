changelog=1.8.1 - Fixed "No parameter definition for the sink 'OUTPUT'" error in 1.8.0.
    1.8.0 - Subirrigation drain spacing from the inverse Hooghoudt equation (new fields ka_sub, subirr_ft and label options), for an irrigation coefficient, water level at the drains and mid-drain water table you enter.
    1.7.0 - Drain spacing from the Hooghoudt equation (water table at the surface) using SSURGO Ksat, for a drain depth and drainage coefficient you enter. New fields ka_ftday, kb_ftday, barrier_ft, spacing_ft and drain spacing label options.
    1.6.0 - Also listed under Vector → Tile Drainage with the other drainage tools (existing menu entry kept). Fixed "provider has been deleted" error when unloading or reinstalling.
    1.5.0 - New series field and label option: first word of the soil name (e.g. Drummer).
    1.4.0 - Trace a field on the map; optional bold field boundary outline on the soil map.
    1.3.0 - Removed the Illinois productivity index fields.
    1.2.0 - Fewer output fields; added Illinois productivity indexes.
    1.1.0 - Soil names stop at the first comma (no slope or flooding phase).
    1.0.0 - First release: SSURGO map units clipped to field polygons, labeled by soil name.
author=Richard Cooke
email=raccooke@gmail.com
about=Give it a field boundary (shapefile or any polygon layer), or trace one by clicking on the map. It sends each polygon to USDA-NRCS Soil Data Access, the database behind Web Soil Survey, and returns the soil map units clipped to the boundary with map unit symbol, soil name, dominant component, drainage class, hydrologic group, acres and Hooghoudt drain spacing for a drain depth and drainage coefficient you enter, plus subirrigation spacing from the inverse Hooghoudt equation. The output is labeled with the soil name, can be saved as a shapefile, and can include the field boundary as a bold outline. Requires an internet connection.
