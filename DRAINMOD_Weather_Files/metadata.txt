qgisMinimumVersion=3.16
description=Click a point on the map to download Daymet daily precipitation and min/max temperature and write DRAINMOD weather files (.RAI, .TEM).
about=Uses the ORNL DAAC Daymet Single Pixel Extraction API (North America, 1980 to present). For the clicked point it writes daily precipitation (mm) and Tmax/Tmin (deg C) as .wea text files, and converts them to DRAINMOD hourly rainfall (.RAI) and daily temperature (.TEM) files. Leap-year Dec 31 (omitted by Daymet) is filled with zero rainfall and Dec 30 temperatures. Requires internet access.
